# Tables Manifest

All tables generated by `experiments/make_tables.py` purely from `results/raw/*.csv`.

Total tables: **6** (limit <= 6).

1. `tab01_benchmarks_selection.{csv,tex}`: E1/E8 equilibrium selection sensitivity across all 7 rules (symmetric vs unrestricted), eps_rel, and r. (Source: `results/raw/e8_selection_benchmarks.csv (+ e1_refinement.csv catch-grid band)`)
2. `tab02_e2_learners.{csv,tex}`: E2/E8 final learner comparison at gamma=0.99, sigma=0.1 across 20 seeds (mean +/- 95% t-CI, per-episode learning cost L_bar_tau_plan against 50-step planner return). (Source: `results/raw/e2_learners.csv (+ e8_learners_by_rule.csv min_total)`)
3. `tab03_e3_unknown_r.{csv,tex}`: E3 unknown-r belief vs known-r MB-EQ baseline separating warm-up vs conditional post-warm-up collapse. (Source: `results/raw/e3_unknown_r.csv`)
4. `tab04_e4_crossplay_paired.{csv,tex}`: E4 pooled co-adapted cross-play own return J1 and paired CRN MB-OA minus MB-EQ differences (with/without request recovery). (Source: `results/raw/e4_crossplay.csv + e4_crossplay_paired.csv`)
5. `tab05_e5_e6_e7_ablations.{csv,tex}`: E5 team baselines and E6 data-amount / prior sensitivity (+ E7 safe exploration). (Source: `results/raw/e5_team.csv + e6_data_amount.csv + e7_safe.csv`)
6. `discretisation_band.{csv,tex}`: E1 grid discretisation sensitivity band (101x51 baseline vs 101x101 catch and 201x51 stock refinements). (Source: `results/raw/e1_refinement.csv`)
